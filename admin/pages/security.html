PulseFit requires administrators to use two-factor sign-in. Set it up below to continue to the dashboard.

Your account

After your password, you will also enter a 6-digit code from an authenticator app on your phone (Google Authenticator, Microsoft Authenticator, Authy, 1Password…). Someone who learns your password still cannot sign in.

Checking…
  1. Open your authenticator app and add an account (usually the + button).
  2. Scan this QR code. If you cannot scan, type the key below instead.
  3. Enter the 6-digit code the app shows.

All administrators

When on, the database refuses all administrator actions from a session that has not entered a code — even with the right password. Make sure every administrator has set up their authenticator first. You can only change this after signing in with your own code.
