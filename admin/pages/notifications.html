Email (Resend)

Booking, billing and order emails, following each member's preferences. Switch on only after the Resend secrets are set (see docs/notifications-setup.md).

Push (Firebase Cloud Messaging)

Phone (Android) and browser alerts. Needs the Firebase service-account secret on the server and the Firebase values in the app build.

Test

Sends a test notification to you. With email switched on it should arrive in your inbox within about a minute, once the scheduler secrets are stored in Vault.
